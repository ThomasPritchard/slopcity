# Chat and HUD quality of life

Town chat reaches the current town. Table chat reaches players with the same casino table open nearby or an occupied seat at that table. Whispers reach one online guest in the same town, selected by profile ID; only the sender and recipient receive the message. The server checks table eligibility and both directions of blocking on every delivery. All destinations share the existing moderation, silence and rate limits. No chat bodies are persisted or placed in replicated state.

Each delivered message has a unique ID and server timestamp. The browser keeps up to 300 lines for the current visit. All, Town, Table and Whispers filters include local moderation notices; All sends to Town. The composer always names its destination, and incoming whispers never change it. Leaving a table disables its composer until the user chooses another destination. New-message counts and a latest button preserve scrollback while reading. `/w`, `/r`, `/town`, `/table`, Enter and Escape provide keyboard access. Desktop history size and text size are saved in this browser.

The existing green/cream HUD design remains. Larger desktop controls apply only to wide viewports with a fine pointer and hover; touch phone/tablet HUD sizing remains unchanged. Global channels across instances, offline whispers, saved chat history and character flair are deferred.

Social, player cards and the leaderboard use native modal dialogs above the game canvas and cinema layers, with Escape and focus restoration. The initially reported invisible popup did not reproduce in a clean local Brave profile before this change. The built release passed native-layer, visibility, hit-test and close/focus checks in headless Brave and WebKit on 12 September 2026. The same journeys covered real whispers, scrollback, desktop 1080p/4K, touch phone/tablet layouts, and a walk to reception and roulette. Three-client protocol checks covered blocking, private delivery, table access and reconnects; physical devices and live voice were not tested.
